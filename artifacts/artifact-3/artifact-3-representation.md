# Artifact 3 – Representation

## System Capability
This artifact implements the system capability **Information Clarification and Alignment**, which supports the Fellowship in identifying and resolving unclear or conflicting information.

## Static Interface Implementation
The interface represents the wireframe designed in Assignment 2 as a static HTML and CSS page.

Files included:
- `src/interface.html`
- `src/style.css`

The interface visualizes the three main states of the communication process:

1. **Shared Message** – a message that is shared with the group.
2. **Needs Clarification** – a message that has been flagged as unclear and requires interpretation.
3. **Resolved** – a message where the group has aligned on a shared interpretation.

## Design Rationale
The goal of this artifact is to make the system capability visible through structure, hierarchy, and layout.

The interface groups related information into clear sections and uses simple visual components to represent different message states.

Buttons are included to indicate possible user actions (e.g., flagging a message as unclear or confirming an interpretation), but they do not implement interactive behavior because the assignment requires a static interface without JavaScript.
